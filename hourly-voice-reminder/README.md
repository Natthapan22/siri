# hourly-voice-reminder

โปรแกรมแจ้งเตือนด้วยเสียงตามชั่วโมงที่เลือก มีหน้าต่าง UI ตั้งค่าได้  
รองรับ **macOS** และ **Windows**

| ระบบ | เสียง | เปิดใช้ |
|------|--------|---------|
| macOS | `say` · Kanya (ไทย) | ดับเบิลคลิก `เปิดแอป.app` |
| Windows | SAPI ของระบบ (เลือกเสียงไทยอัตโนมัติถ้ามี) | ดับเบิลคลิก `OpenApp.bat` |

## Windows — คลิกเดียวจบ

1. คัดลอกทั้งโฟลเดอร์ไปเครื่อง Windows  
2. ดับเบิลคลิก **`OpenApp.bat`** (หรือ `เปิดแอป.bat`)  
3. ถ้ายังไม่มี Python → จะดาวน์โหลดติดตั้งให้อัตโนมัติ (ครั้งแรก 1–3 นาที ต้องมีเน็ต) แล้วเปิด UI  
4. ครั้งถัดไปเปิด UI ทันที

ครั้งแรกถ้า Windows บล็อกสคริปต์: คลิกขวา → Properties → Unblock → OK แล้วเปิดใหม่  
หรือคลิกขวา `OpenApp.bat` → Run as administrator ถ้าเครื่องล็อก Execution Policy แน่นมาก

> อย่าเปิด `main.py` ด้วย IDLE — จะขึ้นหน้าต่างโค้ด/Shell ด้วย

## macOS

ดับเบิลคลิก **`เปิดแอป.app`** — ขึ้นแค่ UI  
(ครั้งแรกถ้าบล็อก: คลิกขวา → Open → Open)

หรือ:

```bash
python3 main.py
```

## ใช้งาน UI

1. กรอกข้อความ (บันทึกอัตโนมัติ)  
2. ติ๊กชั่วโมง (ค่าเริ่มต้นครบ 00:00–23:00)  
3. กด **เทสเสียง** → **เริ่ม**  
4. กด **หยุด** เมื่อไม่ใช้

ตั้งค่าเก็บใน `config.json`

## ตั้งค่าเสียงภาษาไทยบน Windows

โปรแกรมจะเลือกเสียงไทยอัตโนมัติ **ถ้าเครื่องมีเสียงไทยติดตั้งอยู่แล้ว**  
ถ้ากด **เทสเสียง** แล้วพูดไทยไม่ชัด / อ่านเป็นภาษาอังกฤษ ให้เพิ่มเสียงไทยตามนี้:

### Windows 11

1. เปิด **การตั้งค่า** (Settings)
2. ไปที่ **เวลาและภาษา** (Time & language)
3. เลือก **การพูด** (Speech)
4. กด **เพิ่มเสียง** (Add voices) หรือ **จัดการเสียง** (Manage voices)
5. เลือก **ภาษาไทย (ไทย)** แล้วดาวน์โหลดเสียง (เช่น **Pattara** หรือ **Premwadee**)
6. รอดาวน์โหลดเสร็จ แล้วเปิดแอปใหม่ → กด **เทสเสียง** อีกครั้ง

### Windows 10

1. เปิด **การตั้งค่า** (Settings)
2. ไปที่ **เวลาและภาษา** (Time & Language)
3. เลือก **การพูด** (Speech) หรือ **ภาษา** (Language) → **ภาษาไทย** → **ตัวเลือก** (Options)
4. กด **ดาวน์โหลด** ในส่วน **เสียงพูด** (Speech / Text-to-speech)
5. รอดาวน์โหลดเสร็จ แล้วเปิดแอปใหม่ → กด **เทสเสียง** อีกครั้ง

### ทางลัด (Windows 11)

กด `Win + I` → พิมพ์ค้นหา **เสียงพูด** หรือ **Speech** → เข้าเมนูเพิ่มเสียงภาษาไทย

> ต้องมีอินเทอร์เน็ตตอนดาวน์โหลดเสียงครั้งแรก
