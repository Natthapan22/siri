# Hourly Voice Reminder

แจ้งเตือนด้วยเสียงทุก 1 ชั่วโมง

| เครื่อง | กดไฟล์นี้ |
|---------|-----------|
| **Mac** | **`เปิดแอป.command`** |
| **Windows** | **`เปิดแอป.bat`** |

ถ้ายังไม่มี Python → ติดตั้งให้อัตโนมัติ (ครั้งแรกต้องมีเน็ต)  
หยุด: `Ctrl+C`

เปลี่ยนข้อความ: แก้ใน `main.py` (`REMINDER_MESSAGE`)  
Log: โฟลเดอร์ `logs/` (สร้างเองตอนรัน)
