# Hourly Voice Reminder

แจ้งเตือนด้วยเสียงตามชั่วโมงที่เลือก — มีหน้าต่างตั้งค่า

| เครื่อง | กดไฟล์นี้ |
|---------|-----------|
| **Mac** | **`เปิดแอป.command`** |
| **Windows** | **`เปิดแอป.bat`** |

ถ้ายังไม่มี Python → ติดตั้งให้อัตโนมัติ แล้วเปิด **หน้า UI**

### ในหน้าต่าง
- กรอกข้อความ + กด **เทสเสียง**
- ติ๊กชั่วโมง 00–23 (เริ่มต้นติ๊กครบ)
- กด **เริ่ม** / **หยุด**
- บันทึกอัตโนมัติใน `config.json`

Log: `logs/`
