# hourly-voice-reminder

แจ้งเตือนด้วยเสียงตามชั่วโมงที่เลือก — มีหน้าต่างตั้งค่า  
**กดเปิดอย่างเดียว จบ**

| เครื่อง | กดไฟล์นี้ |
|---------|-----------|
| **Windows** | **`เปิดแอป.bat`** |
| **Mac** | **`เปิดแอป.app`** |

## วิธีใช้

1. คัดลอกทั้งโฟลเดอร์นี้ไปเครื่อง  
2. ดับเบิลคลิกไฟล์ตามตารางด้านบน  
3. กรอกข้อความ → กด **เทสเสียง** → กด **เริ่ม**

- Windows ครั้งแรกถ้ายังไม่มี Python จะติดตั้งให้อัตโนมัติ (ต้องมีเน็ต ประมาณ 1–3 นาที)  
- ตั้งค่าบันทึกอัตโนมัติใน `config.json`  
- อย่าเปิด `main.py` ด้วย IDLE

### ถ้า Windows บล็อกไฟล์

คลิกขวา **`เปิดแอป.bat`** → Properties → ติ๊ก Unblock → OK แล้วเปิดใหม่

### ถ้าเสียงไทยบน Windows ไม่ชัด

การตั้งค่า → เวลาและภาษา → การพูด → เพิ่มเสียงภาษาไทย แล้วเปิดแอปใหม่

### ถ้า Mac บอกไม่พบ Python

ติดตั้งจาก [python.org](https://www.python.org/downloads/) แล้วดับเบิลคลิก **`เปิดแอป.app`** อีกครั้ง
